## Retainer Pricer 0.5.1.65

- World pricing now uses live home-world marketboard listings when updating existing listings, including Auto update. Your own retainers are excluded; Data Center and Region continue using Universalis.
- Added a Don't market list and item right-click option to skip new listings and batch selling while allowing whitelisted NPC sales. Exceptions, saved gearsets and Don't vendor remain protected.
- Desynthesis now waits for the Bacon Broth buff after requesting food, even if the game returns a negative item-use result, then continues the same run.
