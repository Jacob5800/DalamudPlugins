## 0.1.5.0

- Added Generate and apply to create a variation and apply it to the open Portrait Editor in one click.

- Added owned frame, background and accent preferences that are favored without excluding other owned designs. Preferences are included in settings backups.
- Added Random under Choose a featured look, choosing a new featured style for each generation.

- Added an optional PA server-bar button that opens Portrait Atelier, disabled by default.
- Settings can be exported to the clipboard and imported with a preview. Import automatically saves a local safety backup.
