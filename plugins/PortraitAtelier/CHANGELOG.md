## 0.1.5.3

- Improve disable/update cleanup: stop callbacks first, attempt remaining cleanup after an error, and ignore repeated shutdown calls.

## 0.1.5.2

- Added Undo last apply and named local presets, included in settings backups.
- Added independent camera, lighting, pose and expression locks.
- Added a camera icon beside the optional PA server-bar button.

## 0.1.5.1

- Background, frame and accent changes can each be enabled or disabled independently, including in settings backups.

- Expanded to 30 featured looks with eight additional community-inspired lighting/composition styles, including Crimson Spotlight, Azure Contour, Shadow Outline and Gallery Close-up. New styles also control directional-light angles.

- Owned designs load automatically from the open editor. Generate captures the current portrait if no base is loaded, and uses random owned designs when no preferences are set.

- Added the installed version in the bottom-right corner.
- Added 12 featured looks inspired by community portrait compositions, with matching owned-pose and expression preferences. New looks are included in the refreshable catalog.

## 0.1.5.0

- Added Generate and apply to create a variation and apply it to the open Portrait Editor in one click.

- Added owned frame, background and accent preferences that are favored without excluding other owned designs. Preferences are included in settings backups.
- Added Random under Choose a featured look, choosing a new featured style for each generation.

- Added an optional PA server-bar button that opens Portrait Atelier, disabled by default.
- Settings can be exported to the clipboard and imported with a preview. Import automatically saves a local safety backup.

## 0.1.4.1

- Added a Discord join button with a recognizable Discord-style symbol at the bottom of the menu, linked to the community invite.
- Added a portrait-themed plugin icon.
